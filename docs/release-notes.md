Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

This release cuts lines the hooks printed for nobody, measured on two weeks of the author's graded deliveries. It points the rotation at the facts most likely stale, and it stops the link step from breaking the links a rebuilt ruling has to where it came from.

- **A bare program needs a second word.** A fact keyed on a one-word command (`ssh`, `python3`, `git`) was pushed at a session's first call of that program, whatever the call did. Those lines were 9% useful and 63% noise. Such a key now needs a word of the fact's own among the command's first terms, not counting the session's repository names, folder and home. A script's path or file name (`scripts/release.sh`) needs none. An area's tool patterns match MCP tools only: `Bash` matched every shell call. On the graded pushes of 3 days: 124 lines to 102, 30 useful to 29, noise 44% to 35%.
- **A line that says the request back is left out.** A scheduled job's own instructions, filed as facts from its earlier runs, came back to every run. A line of 5 distinct words or more is left out when 7 in 10 of them are in the request and it says no only where the request does. Nothing takes its place. On the graded scheduled reviews: 34 lines to 2, the one useful line kept.
- **A short request gets no rule slot and no action line.** A request of fewer than 3 distinct words of 3 letters or more, stop words aside ("deploy now?"), names too little to pick either for. On the graded prompts: 5 noise lines fewer, no useful line lost.
- **The rotation checks first the machine facts whose named path is gone.** A fact of this machine whose description names a path under the home directory that is not there was stale in 27 of a fresh sample of 30. The rotation takes those first and shows the model each missing path. Checked by the model, the first 30 picks held 24 stale facts. The order before took facts no hook delivers, and found 2 stale and 10 superseded.
- **A link to what a fact replaced is no dead link.** A rebuilt ruling links to the statements it was made of. The link step called those links dead: it put a `LINK?` line to the owner for each (293 on the author's store, 284 open in Needs you) and unwrapped them in agents' facts. They are left as they are now, and those items leave Needs you. The 20 links already unwrapped stay so; `eval/curate/link_history.py` lists them.
- **Measuring delivery.** `eval/delivery/deliveries.py` turns Claude Code transcripts into cases, and `eval/delivery/labelled_replay.py` replays graded deliveries at the store commit each hook read, with the session's seen facts. `eval/DELIVERY.md` records what was tried and not shipped.

Upgrading: no index or store format change, and the server is unchanged. An older binary reads what this one writes. Install it where the curator runs: the link step and the rotation run there, and an older curator keeps unwrapping the links above. Install it where the owner opens the app too: an older app still lists the old `LINK?` items, and its Apply the fix would remove the link. A curate unit written by hand needs `tacit rotation --max N` added, with the same `--env-file` it passes to `tacit curate`; `tacit maintain` already runs it. A store clone left mid-run by an older link step may hold an unwrap that was never committed: `git -C <store> status` shows the file, and `git -C <store> checkout HEAD -- <file>` drops it. Any writer is refused a new area tool pattern that does not start `mcp__` (write `mcp__*__Ticketing*`). One a record already holds stays, and lint passes it; one that can only name a harness's tool (`Bash`) matches no call any more: move the program to the area's commands.

Builds for Linux, macOS and Windows on amd64 and arm64 include the CLI, the browser app and a compatible scrump redactor. Git 2.29+ is required. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
