Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

- **Folders with records.** Every project folder can carry a record that code checks: what it is (a repository, a plain folder, an area of ongoing work, a bounded topic), its status (active, dormant, dead, shipped) and how it got there.
  - `tacit assess` has the curator's model decide each folder on evidence code gathers from git and sessions; code checks every answer before it is written.
  - `tacit migrate` copies the facts of a folder folded into another into the folder that replaces it; each old fact points to its copy with `superseded_by`. `tacit rescope --plan FILE` moves the facts a plan names the same way.
  - The hooks deliver nothing from a dead or shipped folder; search and the tree still find it. A search of a folded folder searches the one that replaces it.
- **`tacit review` is the owner's page in every build.** Edit, retire, restore and undo facts, write new rules, and run the Folders page (create a folder, set its status with a reason, add an alias, fold it into another, set an area's tools and commands). Every write is an owner commit. The link carries a token for that run only: it goes to the browser the command opens and is printed only on a terminal, so an agent running the command cannot drive the page.
- **Areas and topics in delivery.** Before an MCP tool call or a shell command that an area's tools or commands match, the PreToolUse hook gives a few of that area's rules and decisions, once a session, in a repo or not (about 50 ms per MCP call). A prompt that names a live topic searches the topic's folder too.
- **The rotation.** `tacit maintain` sends the facts unchecked longest back to the curator's model with the proof code gathers, stamps each one `last_checked`, and retires, redirects, notes or compresses only what the proof shows. It asks you about your own facts instead of changing them. Its cost per fact is logged in `rotation.jsonl` (about $0.01 a fact with Opus); `TACIT_ROTATION_MAX` caps a run.
- **Overviews.** A live folder with 3 or more facts gets an `_overview.md` in which every line cites its facts. `tacit tree <folder> --depth 0` and `tacit_tree` show it.
- **In-place notes.** A fact that still holds while one detail changed keeps its words and gets one dated line, `> superseded <date>: <old> -> <new>`, instead of a rewrite. `tacit_fact` on a replaced fact prints the fact that replaced it first.
- **The local layer reads the records too.** A read-only machine with the local layer keeps its own status for a store folder and its own folders' records in its overlay, never in the clone. The search index holds them with the store's records, and the index built from the store's copy still answers as one built from nothing.

Upgrading: folder records, `areas/`, `topics/`, overviews and `last_checked` are a new store format, and older binaries read it wrong. Every machine that reads the store must run v0.9.0 before anyone runs `tacit format --set`; nothing writes the new format until that marker is set, and `tacit doctor` shows each machine's format and the marker. Rerun `tacit install claude` and `tacit install codex` so the PreToolUse hook also matches MCP tools. Use `tacit review` as the owner's page.

Builds for Linux, macOS and Windows on amd64 and arm64 include the CLI, the browser app and a compatible scrump redactor. Git 2.29+ is required. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
