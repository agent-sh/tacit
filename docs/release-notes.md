Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

This release stops paying for curator and dreamer runs that fail, keeps the work a failed run already paid for, and catches more copies before they are written.

- **Failed runs back off.** A curate run that paid for model calls and completed nothing, because the split, rulings or judge route failed (a provider, authentication or quota error, an invalid answer it could not split further, the conflict index), now counts as a failed run. Nothing pending, or one note's own invalid answer, does not. The next run that may pay waits 30 minutes, then 1, 2 and up to 4 hours, and first sends a one-line probe on the failing route (about $0.002 on Opus). A failed probe doubles the wait; a passed one lets the run go on. Inside a run, a batch that failed on its route is followed by a probe before the next batch pays. The quick run skips its batches until the next try; the daily run still probes. The dreamer backs off the same way when its route fails. The state is in `curate-backoff.json` and `dream-backoff.json` in the state directory, and `tacit doctor` shows it.
- **A failed run's split is kept.** When the rulings pass or the conflict judge failed after the split, the next run split the same notes again and paid again. The split's answer is now kept per note in `curate-splits.json`, and so is the rulings pass's once it answers. The next run takes them if the note has not changed and the checks still pass them, and pays only for the step that failed. Kept answers are dropped when their batch completes, after 14 days, or when the prompts change.
- **The absorber reads content.** A fact of the split was dropped as a copy only when its description matched a curated fact's. Most copies are paraphrases, so they were written. Now a fact is also dropped when every sentence it makes is already in a curated fact it can see: the same scope, user, system or the session's repository, with 80 percent of the sentence's words and every path, number, version and command. Change and negation words must match too. Your words, statements, and notes the reviewer trimmed are never dropped this way, and folder overviews and long imports never count as covers. Paths with placeholders or globs (`.../<id>/apps/*.stderr.log`) now count as specific for both rules, so a new path under a covered directory is kept. Every absorption is listed in the curator's report with the fact that covers it.
- **The held list, opt-in.** `dream_held_chars: on` (or `TACIT_DREAM_HELD_CHARS`) gives each dream window a list of the curated facts its session would be shown and tells the dreamer not to write them again. It is off by default: on the rig it cut repeated notes only within run-to-run noise, for 11 percent more dreamer cost.

Measured on the rig's own data, read-only (2026-10-28):
- **Failed runs.** From 10-21 to 10-28 the curator spent $336.88, and $122.40 of it went on 57 runs that wrote nothing. Most were the quick run between 10-22 and 10-24: it paid the Opus split again every 30 minutes for 27 hours while the judge route (a Grok override whose balance had run out) answered HTTP 402. Replayed run by run under this release's policy, the week costs $216.85: $120 less, with $3.31 paid in failed first batches and 21 probes, and 42 runs skipped. The saving comes from outages. A week without one saves nothing and costs nothing.
- **The absorber.** The rule was replayed on the 5,340 facts the curator wrote in that week, each against the live facts its curation saw, and each fact it absorbs was labelled by hand. At 0.8 it absorbs 40 facts and all 40 are copies: 22 of 22 before the rebuild switch (tuning) and 18 of 18 after it (held out). At 0.75 one of 32 added a detail. That is about 6 facts a day, each a judge pair saved and one copy fewer in the store. Most copies are still paraphrases that no word rule reaches. On the rig's 20,957 live facts the absorber builds in 2.3 s.
- **The held list.** Replayed on 14 windows of the rig's sessions, each with the store as it was before the window, and judged blind by Opus: 131 notes without the list and 120 with it. Copies of held facts went from 20 to 14 and new facts from 66 to 62. Your words were unchanged. Input was 13 percent larger and cost 11 percent more. Two runs of the same prompt differ by about as much, so the list stays off. Model spend for these measurements: $7.73.
- **Delivery.** The 276-case replay gives this release's output byte for byte the same as 0.9.11's.

Upgrading: no index or store format change. New state files in the state directory: `curate-backoff.json`, `curate-local-backoff.json`, `dream-backoff.json` and `curate-splits.json` (`curate-local-splits.json`). Each exists only while there is something in it. The curator's report gains `backed_off`, `probes`, `splits_reused` and `absorbed_by`. The dreamer's report gains `backed_off`, `probes`, `held` and `held_chars`. An older binary ignores all of them.

Builds for Linux, macOS and Windows on amd64 and arm64 include the CLI, the browser app and a compatible scrump redactor. Git 2.29+ is required. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
