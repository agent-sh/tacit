Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

This first public release includes CLI and browser-app builds for Linux, macOS and Windows on amd64 and arm64. Every archive includes a compatible scrump redactor. The install scripts select the platform, verify checksums and test text masking before installing into your account.

Claude Code, Codex, Hermes, Grok, pi, Muse and agy integrations are available. The dreamer, curator, conflict judge and verifier can each use a different runner. Operator settings and provider credentials remain private.

Dreamer jobs commit each successful window, recover pending notes and resume capped work. Batch runtime limits pause cleanly; model and write failures remain visible. The README includes a working example and browser-app screenshots.

Git 2.29+ is required. Model jobs need your chosen native CLI and its provider configuration. Browser builds are included; native desktop-window builds are separate. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
