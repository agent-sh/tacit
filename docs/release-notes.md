Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

This release takes one owner's personal content out of tacit's own repository: the docs, the eval notes, code comments, tests and a few example strings in the binary are generic now, and a CI lint keeps them so (#113, #114, #115, #116). Nothing else in behavior changes.

- **Generic examples in the binary.** The `tacit assess --folders` help, the `tacit_add` schema example and two examples in the assessment prompt are generic. `tacit curate --max-batches` names the batch's limit, 45,000 characters of notes. The `tacit_probe` description and the stale verifier's prompt name the read-only source directories `TACIT_VERIFY_ROOTS` adds, which is what the probe reads.
- **A lint for personal content.** `scripts/privacy-lint.py` fails on words attributed to the owner with a date, Tailscale addresses and tailnet names other than placeholders, home directories of real users (also as Claude Code encodes a project folder), and the words of a private deny list. It reads the list from `--deny FILE`, `TACIT_PRIVACY_DENY` and `$XDG_CONFIG_HOME/tacit/privacy-deny.txt` (else `~/.config/tacit/privacy-deny.txt`), all that are there; the list is never committed. It checks tracked paths and contents. A finding prints its file, line and rule, never the text; a deny-list word prints only as a count, and `--show` prints everything for a local run. CI runs it on every pull request, every push to main and once a day. AGENTS.md states the rule: personal content never enters the repository, fixtures are synthetic, and evidence stays on the machine that made it.
- **Docs and eval notes.** SPEC.md, the README, CONTRIBUTING.md and docs/ state each rule and mechanism without one owner's words, measurements, machines or project names. eval/VALUE.md and the other eval notes keep each measurement's question, method, decision rule, the direction of its result and the decision; tacit's own numbers and the method's statistics keep their values, and the rest stay with the store's owner.

Upgrading: no index, store format or protocol change; the server needs no deploy.

Builds for Linux, macOS and Windows on amd64 and arm64 include the CLI, the browser app and a compatible scrump redactor. Git 2.29+ is required. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
