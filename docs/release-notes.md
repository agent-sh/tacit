Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

This release closes a redaction fault: a batch of texts could come back with a secret of one text unmasked when a hit started in the text before it.

- **Each text is masked as it would be alone.** `RedactAllContext`, and with it `RedactEvents` and every caller, joined its texts into one scrump stream. A hit could start in one text and run into the next without touching the separator. It could be a quoted value a cut left open, a candidate the rule's filter rejects (`token_url: '...`, `$(vault ...)`), or a keyword rule's reach across lines. The scan then resumed past the next text's key and kept its secret, and nothing bisected (#84).
  - The texts now go to scrump as records, each scanned on its own (scrump 0.2.0's `--records`, bundled in this release).
  - Support is detected from scrump's answer. The first records call of a process carries #84's repro ahead of the texts. A scrump that refuses the flag, or takes it and keeps the repro's password, gets the texts joined by the boundary from the issue for the rest of that process. A hit that masks part of the boundary halves the batch. Any other failure fails closed.
  - A text holding a record separator is masked alone instead of being refused.
- **The dreamer's digest is masked line by line too.** Its lines were joined by newlines, which masks never touch, so a crossing hit could not show in the line count. A window is now masked as one text and line by line, and a byte stays masked when either masked it. A keyword at the end of one line still masks the token that starts the next.
- **A cut value is masked to the end.** scrump 0.2.0 masks a credential's quoted value that a cut left open at the end of a text. Before, it needed its closing quote and came back whole.
- **One reader for other programs.** `client/pkg/evidence` exports `RedactRecordsContext` and `ErrNoRecords`, for a program with its own fallback. A program that calls its `RedactAllContext` or `RedactEvents` gets the fix once it requires the client module at this release's commit.
- **Mac setup upgrades an old scrump.** `scripts/mac-setup.sh` checks records mode as well as the text profile. When either fails it rebuilds scrump at the pin, replacing one an installer copied in. A rerun brings a Mac with the previous pin up to 0.2.0.

Upgrading: no index, store format or server change; the server needs no deploy. Upgrade the client on every machine. An older client still joins texts in one stream, on any machine that redacts with it. The bundled scrump moves to 0.2.0, and the installers put it next to tacit. With an older scrump on PATH, the boundary still keeps texts apart, but it is slower, and a value a cut left open comes back whole. `scrump --version` shows which one is on PATH. A source build installs 0.2.0 with `cargo install --force --locked --root ~/.local --git https://github.com/avifenesh/scrump --rev b2b3178c412ee5d99aaf36233d3952c2d4e796ca scrump-cli`; `--force` replaces a scrump an installer copied in.

Builds for Linux, macOS and Windows on amd64 and arm64 include the CLI, the browser app and a compatible scrump redactor. Git 2.29+ is required. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
