Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

This release reads the sessions Codex compresses, and keeps the commands Claude Code runs itself out of your words.

- **Compressed Codex sessions are read.** Codex rolls an old session into a compressed copy (`rollout-<time>-<id>.jsonl.zst`) and removes the `.jsonl`. Tacit read only `.jsonl`, so from the day a session was compressed the dreamer, your history (every quote check, statement and assessment reads it) and the reviewer never saw it again. Now each of them reads the compressed copies too, as a stream (pure-Go zstd, bounded memory), and Codex's `archived_sessions` folder. A session is named by its plain path whichever file holds it, and every offset is in its JSONL bytes, so the dreamer's cursor holds when the session is compressed, and follows it when Codex moves it to `archived_sessions` and back. No harness writes a gzip copy, so none is read.
- **Upgrading does not replay months of history.** The compressed copies are a source of their own to the dreamer: one with no cursor is recorded at its end on the first run after the upgrade, as for any new source. A session compressed after that, and the rest of one the dreamer was reading, are read on. The size of each copy is kept in the dreamer's state, so the idle run every 10 minutes does not read thousands of frames again. To dream the compressed history, rebuild with the compressed copies' sources listed and their cursors at their start.
- **A command Claude Code runs itself is not your words.** A local command (`/model`, `/effort`, `/plugin`, the desktop app's `/auto-mode-setup` wizard) is recorded as a caveat line, the command's echo and its output. Its arguments are input to Claude Code, some filled in by the app (`--expect-sha256 <hash> --apply-file <path>`), and the digest, your history and the reviewer took them as a turn of yours. Now they are the harness's. `/goal`'s condition and a skill's arguments stay yours when you typed them; the skill's own text, with your arguments filled in, is the harness's.

Measured on the rig, read-only (2026-10-27):
- **Compressed sessions.** 2,935 compressed Codex sessions (2,940 by the end of the day), 7.7 GB (36.5 GB of JSONL), June to October, every one in one zstd frame that records its size. They hold 375 owner sessions with 4,010 turns of yours that your history did not have (June 197, July 682, August 1,724, September 1,021, October 390). Reading all of them into your history took 20 s and 167 MB.
- **The dreamer after the upgrade.** On the rig's live dreamer state, 725 of the 2,940 compressed copies already had a cursor from when they were plain: 724 at their end, one 1,389 bytes short of it (less than a run waits for). A scan from that state (nothing saved) recorded every other copy at its end. The first scan read the copies' sizes in 9.4 s; the next took 0.12 s.
- **Slash commands.** Of 27 commands with arguments in the Claude Code transcripts, 14 are local commands, each after its caveat (/plugin 6, /effort 3, /auto-mode-setup 3, /model, /rules); 13 are not (/goal 10, a skill typed in the desktop app, a skill run twice by `claude -p`). Release 0.9.10 already read `/goal`'s condition as yours.
- **Hermes.** The rig's rebuild counted 64 of 158 Hermes sessions from your front ends as unread. They are not yours by tacit's rule (15 delegations, 23 fan-outs, 23 scripted `hermes chat -q` runs, 3 continuations of them), which the dreamer never reads; the rebuild's own selection script tested the source alone. Tacit is unchanged; the script now uses tacit's rule.
- **Delivery.** The 276-case replay gives this release's output byte for byte the same as 0.9.10's.

Upgrading: no index or store format change. The dreamer's state gains `packed` (each compressed copy's size) and a `<glob>.zst` entry in `sources` for each glob; an older binary ignores both and keeps reading plain transcripts only. New dependency: github.com/klauspost/compress (BSD-3-Clause), pure Go on every platform.

Builds for Linux, macOS and Windows on amd64 and arm64 include the CLI, the browser app and a compatible scrump redactor. Git 2.29+ is required. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
