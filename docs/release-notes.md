Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

- **Checked claims.** Code checks the plain claims facts and decisions make against their source: whether a repository exists and its current name (every machine's checkouts, their remotes, and GitHub through `gh`, following renames), a path in a checkout or on the forge's default branch, a version against tags and manifests, and the account or org a URL belongs to. A source that cannot answer says unknown, never a guess. The conflict judge, the rotation, dedupe and the absorber read these checks: none of them keeps a refuted fact over a confirmed one.
- **Statements.** When you say something once in a session ("pikadon is the name, move what needed"), the curator keeps your exact words as a `statement`, with a line of context and its own reading marked as not yours. Agents are shown it as "you said once (day): ...", never as a rule. `tacit statements`, also a step of the full curate, makes it a decision when you say the same thing in another session or when a check agrees, and flags it when a check disagrees; nothing waits on you for that.
- **Orgs.** A project folder named for a GitHub org becomes `orgs/<org>`. Each of its facts moves to the one repository its own paths, URLs or session name, and the rest stay in the org. A session in a member repository gets a few of the org's rules after the repository's own, and search and the tree read the org too.
- **Planned renames.** A folder keeps the name you intend and records the forge's current one: the tree and SessionStart show `pikadon (GitHub: ginza)`. Code decides which name is canonical: your decision first, else the main checkout's directory, else the forge's name. A decision the other way is refused with that check.
- **Folders decided by code.** `tacit assess` checks every project folder's name as a repository. A name the forge renamed folds into the current one. A name that exists nowhere folds into the repository at least half of its facts point at, and a folder named like its org that is a real repository stays the repository's. Names proven to be one repository get one live folder. The same evidence asks the same question, so a folder left for review is asked again only when its evidence changes.
- **Folder roots.** A session outside any git repository, in a place a folder's record names for this machine, gets that folder's facts as a repository's.
- **Chains end at the live fact.** `tacit migrate` and `tacit dedupe` point every replaced fact at the live end of its chain of replacements.
- **The owner's page finds any fact.** A search box at the top of every place of `tacit review` and `tacit app` (press `/`) finds any fact, your rules among them, and the retired and replaced ones when you tick the box. A result opens with its actions: edit, retire or restore, replace with a new rule, undo. `tacit review --fact <name>` (and `tacit app --browser --fact <name>`) opens the page on that fact, and says so plainly when no fact has that name. Replace with a new rule writes your rule and marks the old fact replaced by it, in one commit.

Upgrading: statements and orgs are a new store format (2), and older binaries read it wrong. Every machine that reads the store must run v0.9.1 before anyone runs `tacit format --set`, which moves the store to the new format; until then nothing writes it, and `tacit doctor` shows each machine's format and the marker. The search index is rebuilt on its own the first time it is read. Install `gh` and log in where the curator runs, so checks can ask GitHub.

Builds for Linux, macOS and Windows on amd64 and arm64 include the CLI, the browser app and a compatible scrump redactor. Git 2.29+ is required. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
