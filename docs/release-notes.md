Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

- **Owner content is decided per window, not per session.** Some of your sessions run on their own for weeks while you step in now and then, and in Hermes you write almost every other message. The dreamer took a whole session as yours once it was yours, so weeks of an agent's own work were dreamed as if you were in it. Now each dream window decides. A window with at least one turn of yours (as tacit already decides who typed a turn, messages you type mid-turn included) is yours. A window with none is an agent's, also inside your session.
- **A setting for the agents' windows.** `dream_agent_windows` (`TACIT_DREAM_AGENT_WINDOWS`, `tacit dream --agent-windows`) says what the dreamer does with a window that has no turn of yours: `all` dreams it, `recent:<days>` dreams it only when it is that recent, `none` never dreams it. The default is `all`, so nothing changes until you set it. A window that is not dreamed is passed over: its transcript's cursor moves past it, as past a window with nothing in it, and the run's summary and meter line count it.
- **Your turns keep their context.** When the setting leaves out a window's agent content, a window of yours is cut to your turns, each with the 12 lines before and after it, and a line saying how many lines were left out in each gap. Measured on the rig's 4,359 turns of yours, 12 lines reach the agent's text you were answering for 93% of them, which is every turn whose window holds one, the agent's first reply for 91% and its second for 73%. They keep 38% of the characters of your windows.
- **Measured on the rig (read-only, 2026-10-24).** The rebuild's selection holds 158 transcripts of yours and 158 Hermes sessions: 912 windows, 708 of them with a turn of yours and 204 without. Of the 465 windows the stopped rebuild has left, 311 have a turn of yours. Cut to your turns, they send 4.06 million characters instead of 15.9 million.
- **A dry run counts what it would send.** `tacit dream --dry-run --max-calls 0` now prints the windows it would dream and their characters, before any cap, at no cost.

Upgrading: no store or index change (store format 4, search index schema 15). The dreamer's cursors carry over: a window already dreamed keeps its identity whatever the setting. Set `dream_agent_windows` only if you want fewer agent windows dreamed.

Builds for Linux, macOS and Windows on amd64 and arm64 include the CLI, the browser app and a compatible scrump redactor. Git 2.29+ is required. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
