Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

This release fixes two faults on the curator's machine, closes a fault in the server's secret scan before any push hit it, fixes the daily platform smoke, and adds a reader of session history other programs can use.

- **A rulings answer with a sentence before it is sent back.** For a note with no owner words, the curator's rulings pass is asked for every ruling the split missed, and there is none. Asked for "a JSON array (possibly empty)", Opus 5.5 often explained the empty answer first: "The note is an agent observation with no quoted owner words, so there are no rulings to extract. []" (52 of 110 calls). Code refused the answer whole and did not send it back, so a note alone in its batch failed the run. From 03:33 on 10-30, every quick curate that took the newest note exited 1. The prompt now says the empty answer is `[]` and nothing else, and none of 110 calls had a sentence. The rulings pass also sends an answer that is no JSON array, or does not parse, back to the model once, like one refused for its entries; 52 of 52 came back clean. A second refusal still fails the batch. The method is `client/tools/envelope`.
- **A pair whose fact was replaced moves to the live facts.** The findings v0.9.15 named as stranded were pairs one of whose facts a third fact had replaced, so the verifier's "keep the other" was refused every time. Before it sends anything, `tacit verify` now follows each side of such a pair to the live fact at the end of its supersede chain. It closes the finding with a `moot` record and raises the pair of live facts as a new finding, which it verifies in the same run. When a side has no live successor, or both lead to one fact, the finding is closed as moot with the reason. Two kinds of finding are not moved: one with an owner note, on which a verdict becomes their question, and one with a fact missing from the store, which takes "both" as before. A closure the store no longer agrees with, for example after its supersede is undone, is reopened by the curator and moved again or sent. The page shows the record, and reopening it changes no fact. `tacit verify --max 0` only moves such pairs and sends nothing.
- **Slack and Tailscale tokens take two steps, like `sk-`.** The server's secret scan took `tskey-` or a Slack prefix and any 10 letters, digits or hyphens for a key. A fact name with such a segment (`tskey-auth-expires-in-90-days`) would therefore refuse every curator push that named it. No stored fact had one yet. A token is now a key only when it holds what a real key has. For Slack that is an uppercase letter, a run of 20 letters and digits, a run of 10 digits, two 6-digit ids, or a legacy workspace token's version digit. For Tailscale it is an uppercase letter (a key id ends in `CNTRL`) or a run of 20.
  - On 100,000 random keys of each documented shape, every one is refused. That now includes Slack's refresh, app-level, `xoxo-`, client session and session cookie tokens and webhook URLs, which the old rule let through.
  - Two shapes the old rule caught now pass: a legacy Slack workspace token without its version digit (1 in 230 at 10 characters), and a `tskey-` secret of under 20 lowercase characters, which no documented key is.
  - Names with such a segment go from 99.5 to 99.9% refused to none.
  - A blob with no such token skips the new steps, so a push costs what it did.
  - The method is `eval/secrets/token_rules.py`.
- **The platform smoke runs again.** Since 10-22 the daily `portable client` run failed on every platform. The smoke started the browser app with `--no-open` on a pipe, which the app refuses because the page's link carries its token. The smoke is now its own browser opener and takes the link from there.
- **One reader of session history.** `client/pkg/evidence` exports the reader tacit uses for Claude Code, Codex, pi and Hermes sessions, tool calls with their results included. A saved `State` resumes a growing session from where it stopped, so a follower pays only for what was added. Two attribution fixes in the shared rule reach the dreamer, the corpus and the reviewer too. A desktop-app paste inside a typed turn is an agent's piece. A turn that opens with `Wake nonce=` is the harness's: 310 such turns had counted as the owner's.

Upgrading: no index or store format change. An older binary reads what this one writes; its page shows a `moot` record as an answer. Deploy the server first for the new secret scan: an upgraded client's checks take names an old server still refuses.

Builds for Linux, macOS and Windows on amd64 and arm64 include the CLI, the browser app and a compatible scrump redactor. Git 2.29+ is required. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
