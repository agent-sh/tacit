Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

- **What you type while the agent works is yours.** Claude Code does not record a message you type mid-turn as a turn of yours: it keeps it as a queued message, delivered after the tool the agent was running. The dreamer never read those, so a rule you gave mid-turn was never dreamed. You give many of your directions that way. Now such a message is your turn wherever tacit reads your words, in the place it was delivered: the dreamer's digest, your words for the quote check and the quote ledger, statements, and the reviewer. A queued task notification or another agent's message is still not yours. Codex, pi and Hermes record a message you steer into a running turn as an ordinary message of yours, and tacit already read those.
- **Measured on both machines (read-only, 2026-10-24).** On the rig, 448 messages typed mid-turn in 51 of 5,634 Claude Code sessions; 220 of the 551 dream windows of those sessions change, and 16 of them had no line of yours before, so no rule or statement could come from them. On the Mac, 289 in 16 of 47 sessions, and 94 of 133 windows change. Your words for the quote check had most of them already, from Claude Code's prompt history; 67 on the rig and 12 on the Mac were in no turn of yours until now. Codex on the rig had 50 steered messages, pi 25 and Hermes 87, all read already.
- **Every note an agent saves is checked against the conversation it came from.** Agents misread you, and their notes were trusted as soon as they were written. Now the reviewer (Opus) reads the session each agent note came from and judges the note: correct, uncertain or wrong, with a reason. It covers `tacit add` and `tacit_add` from Claude Code, Codex and pi, Hermes's memory writes, and memories imported from the agents' own memory systems. It reads the session the way the rulebook mod does. Only the lines you typed count as yours. A side agent's note, a task report or a hook's text is shown as a note, even when it claims to quote you. It is on by default and runs in every curate (`reviewer: off` in the settings turns it off). Dreamer notes are not reviewed, since the dreamer reads your sessions already.
- **What the verdict does.** A note judged correct is delivered as "agent note (date; checked against its session)" and ranks above unchecked agent notes, though still below your own words. An uncertain note is delivered as "unconfirmed" and ranks lower. A note judged wrong is not curated: it stays in the inbox, and its reason is kept in the reviewer's ledger. On this Mac, where agent notes stay on the machine, no hook delivers a wrong note, while search still finds it, marked. A note whose session is not on the machine where it is reviewed gets no model call. It stays a low-weight agent note and is never trusted. A fact with no verdict is delivered exactly as before.
- **Rulebook's verdicts count.** When the rulebook mod has already reviewed a save in its Claude Code session, tacit takes that verdict instead of asking the model again.
- **Questions come to you in the session you are in.** You said "switching to another location is not comfortable and I will probably not do it". So an uncertain note becomes a short question that the agent asks you at the end of its reply, in Claude Code, Codex, pi or Hermes: what was saved, from which session and day, "right? yes / no / correct it". A question comes only to a session it belongs to: the same repository, the folder the note's session ran in, or a prompt about the same thing, as code decides. Each session gets at most 2 questions, one at a time. At most 12 wait, and each one expires after 30 days or 3 sessions without an answer. A question is dropped when something later settles the note. With no question waiting, nothing changes.
- **Only your own answer counts.** Code reads your answer from your own next turn in the transcript, after the agent asked. Another agent saying "the owner says yes", a task notification, or an agent's own text is never your answer. Yes keeps the note as yours ("you confirmed", ranked with your statements). No retires it, along with your reason. A correction in your words ("correct it: ...") becomes a statement of yours that replaces the note. In Claude Code the open questions can also wait in the rulebook pane, with a small patch to the mod (not applied here; the patch file is next to these notes).
- **Measured on a copy of this Mac's store.** The store holds 510 agent notes: 12 from Claude Code, 20 from Hermes and 478 imported memories. The 209 of them that name a session all name sessions on the rig. The Mac's own 10 agent notes name none, so the Mac's reviewer has nothing it can check yet; from this release on, new notes record their session. As a test, 30 of the Mac's own Claude memories with their sessions on the Mac were reviewed with Opus. They cost $7.42 in all: $0.25 a note on average, $0.07 to $0.38, about a minute each. The verdicts were 13 correct, 13 uncertain and 4 wrong. Three independent checks read 10 of those verdicts against the sessions themselves. They agreed with 7, partly agreed with 2 and disagreed with 1, and agreed with all 4 wrong verdicts. Two of the misses came from your messages typed while the agent was working, which the reviewer did not read; it reads them now, and those two notes then got the checkers' verdicts.

Upgrading: this is store format 4 and search index schema 15 (the index rebuilds by itself). Format 4 lets curated facts carry the verdict in their frontmatter. Until you run `tacit format --set` on every machine running this release, the verdict lives in the reviewer's ledger alone, and every reader applies it the same way. The reviewer judges notes created from its first run on; `tacit reviewer --backfill` judges older ones (about $0.25 a note on the measurement). For pi, run `tacit install pi`, which writes the extension that asks the questions.

Builds for Linux, macOS and Windows on amd64 and arm64 include the CLI, the browser app and a compatible scrump redactor. Git 2.29+ is required. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
