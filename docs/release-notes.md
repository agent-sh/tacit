Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

- **A sync never leaves a half-done checkout.** The network part of a sync still has a deadline; the checkout of what arrived now has its own (ten minutes) and is never cut off half way. Before this, a large pull that ran out of time left the clone half updated with a stale `index.lock`, and every later sync refused it as dirty. A caller with too little time left for a large update (a session's start hook) leaves it for the next sync and touches nothing.
- **Sync finishes an interrupted update by itself.** When a clone is dirty only because an update stopped half way, sync proves it file by file: every changed or new file holds the content (or the start of the content, for the file git was writing) of the server's version or of a commit on the way to it, every missing file was deleted on the way, and nothing is ignored. It then finishes the update and logs what it did on stderr and in `.git/tacit-sync.log`. A stale git lock is removed only when the git that held it is gone, or after 15 minutes when no tacit checkout claims it. Any other change in the clone is refused as before, now with the first file that is not the server's. A writer clone with local commits is never reset.
- **needs-review is worked on, not parked.** You may review a folder, but nothing waits for you. Each run, a folder left for review goes back to the curator with more evidence than last time: facts in other folders that name it, the sessions behind them, its repository's recent activity on GitHub (last push, newest commits and who made them, latest release), what was decided for folders with near names and for the same owner's other repositories, and your own words that name it. It waits only when that wider search finds nothing new, and even then it is tried again after a week. The rotation includes these folders too. Every attempt is logged in `assess-attempts.jsonl` in the state directory. On three copies of the Mac's shadow store, folders left for review went from 65 to 71 down to 9 to 11, and the folder statuses that differed from one run to the next went from 33 to 16. The first assessment of that store cost $5.5 to $5.9 instead of about $3.1; after that, a folder that keeps waiting costs about 5 cents a week.
- **Flagged statements and held moves are tried again.** A statement a check disagrees with is read again with that check shown, the next run and then weekly, in case the first reading got your words wrong. A fact the migration held for you moves as soon as the reason is gone, and its question is closed; a quote kept in the ledger under another fact's name now counts as backing.

Upgrading: nothing to do. The first assessment after the upgrade asks every folder left for review once more, with its extra evidence. Install `gh` and log in where the curator runs, so it can read the repositories' activity.

Builds for Linux, macOS and Windows on amd64 and arm64 include the CLI, the browser app and a compatible scrump redactor. Git 2.29+ is required. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
