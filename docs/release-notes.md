Tacit keeps memory for coding agents in Markdown and git. Use a local store or share one across machines.

This release gives a name two files hold a way out. `tacit dedupe` raises it as a finding about the two files, the owner answers it on the review page, and an agent that can tell which file stands marks it with `tacit review apply`.

- **A name two files hold is raised for review.** Names are unique in a store, but a tool outside tacit can leave one name in two live curated files: a copy in a second folder. Findings, marks and questions are all keyed by names, so nothing could retire one of the two files or ask about them (#109).
  - `tacit dedupe` raises each such pair once, in `review/<date>-names.md`, the earlier file first. `tacit dedupe --names` raises them alone, retiring no copy and pointing no chain, and its `--dry-run` lists them.
  - The review page and tacit app show the two files side by side, each read by its path, with What git shows for both. Keep one, and the other gets `superseded_by` the name, which then reads as the kept file; or keep both. A name more than two files take part in takes no answer there: the page names the other files, and the owner retires the copies one by one.
  - An agent marks it with `tacit review apply`, naming the two paths as `a` and `b` and the one it keeps, with its evidence. The guards of every agent mark hold: the owner's ruling, their words, their note or their earlier keep of the name turns the mark into their question, and `owner` asks it outright. `tacit questions` lists the open ones; `tacit questions close` does not take them; the verifier and the rotation leave them alone.
  - A copy retired into its own name ranks last among the name's files: in the lookup by name (`tacit_fact`, `tacit fact`, `tacit resolve`), on the review page and in tacit app, and in the overview step and the rotation. It never stands for the name again, whatever becomes of the file kept, and `tacit resolve` takes the name after a keep. The rulings audit gives such a copy no endorsement.
  - tacit app acts on a file whose name another file holds by its path, so Retire, Restore, Undo and Edit change the file it shows.

Upgrading: no index, store format or protocol change; the server needs no deploy. Install it on the machine that writes as the curator, which runs `tacit dedupe`, and on every machine whose tacit app or review page the owner answers on: an older client shows no name finding. To raise the names a store already holds, run `tacit dedupe --names --dry-run`, then `tacit dedupe --names`, as the curator.

Builds for Linux, macOS and Windows on amd64 and arm64 include the CLI, the browser app and a compatible scrump redactor. Git 2.29+ is required. [Setup and platform validation](https://github.com/agent-sh/tacit/blob/main/docs/portable.md).
